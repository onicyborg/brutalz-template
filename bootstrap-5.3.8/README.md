# Bootstrap 5.3.8 runtime

Only the upstream distribution used by this template is retained:

- `dist/css/bootstrap.min.css` and its source map.
- `dist/js/bootstrap.bundle.min.js` (includes Popper) and its source map.
- `LICENSE` (MIT).

These vendor files are unmodified. Theme overrides belong in `assets/css/theme.css`.
Upstream documentation, examples, tests, Sass sources, build tools, and alternative distributions are not needed by this project and have been removed.

Original release: https://github.com/twbs/bootstrap/releases/tag/v5.3.8
For Sass compilation, obtain the upstream source separately and set up your own Sass build pipeline; this repository generates HTML only.
