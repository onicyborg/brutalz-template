Collapse

Panel sederhana, multiple targets, dan accordion.

Semua komponen

Simple

Satu tombol untuk satu panel.

Ide yang baik butuh ruang. Panel ini memakai Collapse Bootstrap.
Lihat markup 
<div class="demo-row">
<button type="button" class="btn btn-primary" data-bs-toggle="collapse" data-bs-target="#simplePanel" aria-expanded="false" aria-controls="simplePanel">Buka / tutup panel</button>
</div>
<div class="collapse" id="simplePanel">
<div class="demo-inset bg-green">Ide yang baik butuh ruang. Panel ini memakai Collapse Bootstrap.</div>
</div>

Multiple targets

Kontrol panel secara terpisah atau bersamaan.

Ruang untuk ide pertama.
Ruang untuk ide kedua.
Lihat markup 
<div class="demo-row">
<button type="button" class="btn btn-primary" data-bs-toggle="collapse" data-bs-target="#multiOne" aria-expanded="false" aria-controls="multiOne">Panel pertama</button>
<button type="button" class="btn btn-warning" data-bs-toggle="collapse" data-bs-target="#multiTwo" aria-expanded="false" aria-controls="multiTwo">Panel kedua</button>
<button type="button" class="btn btn-dark" data-bs-toggle="collapse" data-bs-target=".multi-demo" aria-expanded="false" aria-controls="multiOne multiTwo">Keduanya</button>
</div>
<div class="row g-3">
<div class="col-sm-6">
<div class="collapse multi-demo" id="multiOne">
<div class="demo-inset bg-purple">Ruang untuk ide pertama.</div>
</div>
</div>
<div class="col-sm-6">
<div class="collapse multi-demo" id="multiTwo">
<div class="demo-inset bg-yellow">Ruang untuk ide kedua.</div>
</div>
</div>
</div>

Accordion

Satu panel terbuka pada satu waktu.

Template Bootstrap dengan karakter Neubrutalism.

Ya. Ubah token --neo-* pada stylesheet tema.

Tidak. Seluruh aset demo tersedia lokal.
Lihat markup 
<div class="accordion" id="componentAccordion">
<div class="accordion-item">
<h3 class="accordion-header">

</h3>
<div id="accordionPanel0" class="accordion-collapse collapse show" data-bs-parent="#componentAccordion">
<div class="accordion-body">Template Bootstrap dengan karakter Neubrutalism.</div>
</div>
</div>

</h3>
<div id="accordionPanel1" class="accordion-collapse collapse" data-bs-parent="#componentAccordion">
