Hello, builder.

BRUTAL. adalah template admin HTML statis dengan tema Neubrutalism. Grid, utilities, dan interaksi dasar memakai Bootstrap asli. Lapisan tema memberi garis tegas, pastel, dan bayangan solid.

npm run dev # Buka http://localhost:4173 # Atau buka index.html langsung di browser.

Python 3 diperlukan untuk server lokal dan generator. Tidak ada dependensi runtime CDN; jQuery lokal dimuat hanya pada halaman demo tertentu.

Bootstrap dulu, tema setelahnya.

Urutan stylesheet penting. Semua kelas Bootstrap tetap tersedia.

<link rel="stylesheet" href="bootstrap-5.3.8/dist/css/bootstrap.min.css">
<link rel="stylesheet" href="assets/css/theme.css">
<button class="btn btn-primary">Mulai membangun</button>
<script src="bootstrap-5.3.8/dist/js/bootstrap.bundle.min.js"></script>
<div id="sidebar-root"></div>
<script src="assets/js/sidebar-config.js"></script>
<script src="assets/js/sidebar-icons.js"></script>
<script src="assets/js/sidebar.js"></script>
<script src="assets/js/app.js"></script>

Gunakan .bg-purple, .bg-yellow, .bg-green, .bg-orange, atau .bg-blue untuk warna pastel. Grid menggunakan .row dan .col-*.

Ganti warna, pertahankan karakter.

Edit token di awal assets/css/theme.css. Source Bootstrap vendor tetap utuh sehingga lebih mudah diperbarui.

:root {
  --neo-purple: #c4a8f5;
  --neo-yellow: #f9de6e;
  --neo-ink: #232420;
  --neo-paper: #f5f4ef;
  --neo-shadow: 4px 4px 0 var(--neo-ink);
}

Menambah halaman

  1. Salin blank.html ke nama halamanmu.
  2. Ubah judul, breadcrumb, data-page, dan isi elemen <main>. Daftarkan halaman di assets/js/sidebar-config.js; sidebar dan pencarian otomatis mengikuti konfigurasi ini.
  3. Untuk perubahan topbar/footer dan konten hasil generate, edit scripts/build.py, lalu jalankan npm run build.
  4. Hubungkan form dan data ke backend pilihanmu.
Generator menimpa HTML hasil generate. Simpan perubahan permanen di generator, atau gunakan salinan HTML dengan nama baru.

Interaksi & data

Proyek, tugas, agenda, profil, dan preferensi disimpan dengan prefix brutal. di localStorage. Data hanya berada di browser, dan berbeda antar origin.

Angka statistik adalah ilustrasi tetap. Grafik SVG mendukung pergantian periode; enam halaman library grafik memakai data ilustratif. Login/register, subscribe, post, dan kontak adalah demo lokal; tidak ada sesi autentikasi, transaksi, pengiriman newsletter, atau pesan kontak.

Cakupan & pengembangan

Terinspirasi cakupan admin Otika, disusun ulang untuk Bootstrap 5. Starter ini bukan salinan satu per satu seluruh plugin Otika.

Chat dan email tersedia sebagai simulasi lokal. Pengiriman nyata dan upload server belum diintegrasikan. Post dan subscribe disimpan hanya di browser; kontak menampilkan pratinjau tanpa mengirim pesan. Google Maps memerlukan API key browser dan billing; peta vektor berjalan lokal tanpa key. Tambahkan library hanya ketika fitur tersebut diperlukan; pin versi dan muat per halaman.

Menambah halaman dengan rapi

  1. Gunakan nama file lowercase-kebab-case.html dan nilai data-page yang sama tanpa ekstensi.
  2. Tambahkan halaman ke assets/js/sidebar-config.js. Gunakan id unik untuk setiap dropdown; sidebar dan pencarian membaca konfigurasi ini.
  3. Tulis konten permanen di modul scripts/*_pages.py atau scripts/build.py. Generator akan menimpa HTML hasil build.
  4. Tempatkan style di assets/css/, interaksi di assets/js/, dan vendor berlisensi di assets/bundles/. Muat bundle hanya pada halaman terkait.
  5. Jalankan npm run build lalu npm test. Periksa desktop, mobile, keyboard, dan tautan sebelum commit.

Template statis dapat dibuka langsung lewat index.html atau server npm run dev. Aset SVG asli tersimpan di assets/img/; sumber dan lisensi vendor dirinci di README proyek serta folder bundle.
